# Instructions for English codebase translations

## 1. Class name translation

Start by translating the class name inside the file using F2 in Visual Studio Code. Then, go through each file where an error appears in the Unity Editor and replace the old class name with the new one.

## 2. Public member translation

After that, do the same for any other public members in the original file.

## 3. Private code translation

Once all public members have been translated, you can start translating the private code in the file with less caution.

## 4. Comment translation

Now, you can translate the comments in the original file into English.

## 5. File rename

Finally, rename the file to its corresponding English name.
